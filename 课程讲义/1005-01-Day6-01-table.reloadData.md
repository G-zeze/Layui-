# Day 6-01：table.reloadData —— 换一份数据，让表格重画

## 0. 先接上昨天留下的问题

Day 5-08 你观察到：点"删除"并确认后，那一行消失了，但分页条不变；翻页或刷新，被删的行又回来了。

原因：`obj.del()` 只把**页面上**那一行擦掉，**`data` 那个数组一点没变**。表格每次重新画（翻页、刷新），都是按 `data` 画的，所以又回来了。

要真正"删掉"，必须做两件事：**改数据 → 让表格按新数据重画**。第二件事就是今天的内容。

## 1. 它做什么

用一个比喻（只用来理解效果）：`table.render` 像在白板上抄了一份名单。名单本身在你的代码里（`data` 数组）；白板是页面上的表格。

- `obj.del()`：只擦掉白板上的一行字，名单没动。
- `table.reloadData(...)`：你递给它一份**新名单**，它把白板擦干净，按新名单重新抄一遍；表头、列设置不动。

所以"搜索、筛选、真删除、编辑后刷新"，本质上都是同一个动作：**准备一份新数组 → `reloadData`**。

## 2. 最小示例（课程表，不是你的练习）

```js
const courses = [
    {id:1, name:"HTML"},
    {id:2, name:"CSS"},
    {id:3, name:"JavaScript"}
];

table.render({
    elem: "#courseTable",
    cols: [[ {field:"id", title:"编号"}, {field:"name", title:"课程名"} ]],
    data: courses
});

// 以后某个时刻（比如点了按钮），换成只有一门课的新数组：
table.reloadData("courseTable", {
    data: [ {id:3, name:"JavaScript"} ]
});
```

结构树：

```text
table.reloadData( "表格id" , { 要换的配置 } )
├─ 第 1 个参数  表格 id          就是 elem 指向的那个 <table> 的 id（去掉 #），和 checkStatus("…") 里是同一个名字
└─ 第 2 个参数  配置对象          只写要换的，这里是 data: 新数组；cols 等不用再写
```

一句话规则：**`reloadData` 不重建表头，只用新的 `data`（和 `page` 等）重新画数据行；它不修改你原来的数组。**

> 注意：`table.render` 的 `elem` 写 `"#courseTable"`（带 `#`）；`reloadData` 的第一个参数写 `"courseTable"`（不带 `#`）。和 `checkStatus` 一样。

## 3. 新的 JS 点：数组的 `filter`

要"只看女生"，得先从 8 个学生里挑出 4 个，得到一份**新数组**。数组自带 `filter` 方法：

```js
const girls = students.filter(function(s){
    return s.studentGender === "女";
});
```

它的运行过程，和你学过的 `templet:function(d){}` 是同一种模式——**函数是你写的，调用的人不是你**：

```text
students.filter( 函数 )
├─ 数组对里面的每一个元素各调用一次这个函数
├─ 每次调用，把当前这一个学生对象交给参数 s
├─ 函数 return true   → 这个学生留下
├─ 函数 return false  → 这个学生丢掉
└─ 最后把留下的学生装进一个新数组交给你；原数组 students 不变
```

- `===` 是"是否完全相等"，和 `if(obj.event === "edit")` 里的是同一个。
- 得到的 `girls` 就是普通数组，可以直接交给 `reloadData` 的 `data`。

一句话规则：**`filter` 的函数里 `return` 一个"是/否"，是的留下。**

## 4. 一个容易遇到的现象：页码（做完下面练习的第 4 项测试后再看）

我在 Layui 2.13.9 里实测过：假设现在在第 2 页，点"只看女生"，新数组只有 4 条（`limit:5` 只需 1 页），但**表格没有自动回到第 1 页**，会显示成空白。

原因：`reloadData` 默认保持"当前页码"不变，而第 2 页已经没有数据了。

解决：同时告诉它回到第 1 页——

```js
table.reloadData("studentTable", {
    data: girls,
    page: { curr: 1 }       // curr = 当前页码，写 1 就是回到第 1 页
});
```

一句话规则：**换了一份条数不同的数据，就同时写 `page:{curr:1}`，让表格回到第 1 页。**

## 6. 常见错误（先自查）

- 第一个参数写成 `"#studentTable"`（多了 `#`）：找不到表格实例。
- 点击登记写进了 `table.on(...)` 函数里面（写错层）：要点过一次编辑/删除之后才会生效。
- `filter` 里的函数忘了 `return`：筛出来是空数组，表格显示"暂无数据"。
- `s.studentGender` 的键名和 `data` 里不一致：同样筛不出东西。
- `reloadData` 的配置对象忘了写 `data:`，直接写了数组。
