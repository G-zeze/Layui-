## 0. 全景：一次请求经过哪几步

```text
浏览器（你的 Layui 页面）                         服务器（main.py）
fetch("/api/students?keyword=张")  ── 请求 ──▶   uvicorn 收到，交给 app
    方法：GET                                     app 按"方法 + 路径"找到登记过的函数
    路径：/api/students                           调用这个函数：get_students(keyword="张")
    查询参数：keyword=张                          函数 return 一个列表
                                   ◀── 响应 ──   FastAPI 把列表转成 JSON，状态码 200
.then(res → res.json() → list)
students = list → reloadData → 表格
```

后面学的每个知识点，都是这张图里某一格的写法。

## 1. 基础名词（先认识，用到时再细讲）

| 名词 | 是什么 | 对应：你在哪里见过 |
| --- | --- | --- |
| 请求 | 浏览器发给服务器的一次"要东西 / 送东西" | 地址栏回车、`fetch(...)` 都会发请求 |
| 响应 | 服务器回给浏览器的东西 | 浏览器里看到的 `{"msg":"你好"}` |
| 方法（官方叫"操作"） | 这次请求想干什么：`GET` 拿、`POST` 新增、`PUT` 修改、`DELETE` 删除 | `@app.get`、`@app.post`…；地址栏打开网址永远是 `GET` |
| 路径 | 网址里端口后面、`?` 前面的那一段 | `http://127.0.0.1:8000/api/students?keyword=张` 里的 `/api/students` |
| 路径参数 | 路径里会变的那一段 | `/api/students/2023001` 里的 `2023001` |
| 查询参数 | `?` 后面的 `名字=值`，多个用 `&` 连接 | `?keyword=张&page=1` |
| 请求体 | 随请求一起送过去的一包数据（GET 不用它） | 新增学生时，把整个学生对象送给服务器 |
| JSON | 前后端都看得懂的数据文字格式 | Python 字典 ⇄ JSON 文字 ⇄ JS 对象 |
| 状态码 | 响应附带的三位数字，说明这次请求的结果 | 200 成功、404 找不到、405 方法不对、422 数据不合格 |
| 接口 | 一个"方法 + 路径"和它对应的函数 | `GET /api/students` 是一个接口 |
