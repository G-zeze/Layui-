## 1. 环境：在项目里建一个虚拟环境 `.venv`

**虚拟环境是什么：** 项目文件夹里的一个独立小 Python（文件夹叫 `.venv`），这个项目装的包（fastapi、uvicorn）只装在它里面，不影响电脑上的其他项目。
**对应：** 像 `layui-v2.13.9/` 放在项目里一样，项目要用的东西放在项目自己身上。换电脑后只要重新建一次。
**为什么用 `venv` 不用 conda：** Python 自带，不用另外装软件；VS Code 会自动认出项目里的 `.venv`。

在 VS Code 打开 `D:\Dev\Projects\Layui-`，菜单"终端 → 新建终端"（默认是 PowerShell），逐行输入：

```bash
python --version                         # 看电脑上有没有 Python：要 3.10 或更高
python -m venv .venv                     # 用 Python 自带的 venv 模块，在当前文件夹建虚拟环境，文件夹名 .venv
.venv\Scripts\Activate.ps1               # 进入虚拟环境：成功后命令行最前面出现 (.venv)
python -m pip install fastapi uvicorn    # 把两个包装进 .venv
python -c "import fastapi, uvicorn; print(fastapi.__version__, uvicorn.__version__)"   # 打印版本号，确认装好
```

| 看到                                                      | 说明 / 怎么办                                                                                                                                            |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `python --version` 显示 `Python 3.10` 或更高          | 往下做                                                                                                                                                   |
| 显示 3.9 或更低                                           | FastAPI 现在要求 3.10 以上，先装新版 Python（下一行）                                                                                                    |
| 什么都不显示、弹出微软商店、或"无法将 python 项识别为..." | 没装 Python。去 python.org 下载 Windows 安装包，安装第一页**勾选 `Add python.exe to PATH`**，装完**关掉 VS Code 再打开**，重新从第一行开始 |
| `Activate.ps1` 报"禁止运行脚本"                         | 先运行`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，问你时输入 `Y`，再重新运行 `.venv\Scripts\Activate.ps1`（只需设一次）                 |
| pip 下载很慢或超时                                        | 命令后面加`-i https://pypi.tuna.tsinghua.edu.cn/simple`                                                                                                |
| 最后一行打印出两个版本号                                  | 环境装好了                                                                                                                                               |

**以后每次打开新终端：** 先看最前面有没有 `(.venv)`；没有就运行 `.venv\Scripts\Activate.ps1`。VS Code 右下角选了 `.venv` 的解释器后，新终端一般会自动进入。

`.venv` 不进 git（已写进 `.gitignore`），换电脑时重新运行上面几行就行。

## 2. 示例代码（示例用 `/api/ping`，你的任务写 `/api/hello`）

```python
from fastapi import FastAPI     # 导入：从 fastapi 包里拿出 FastAPI 这个类

app = FastAPI()                 # 创建应用实例，名字叫 app：所有接口都登记在它身上

@app.get("/api/ping")           # 路径操作装饰器：登记"GET + /api/ping"，交给下面的函数处理
def ping():                     # 路径操作函数：有人访问 /api/ping 时，FastAPI 调用它
    return {"ok": True}         # 返回字典：FastAPI 把它转成 JSON 发回浏览器
```

启动（终端当前目录必须是 `D:\Dev\Projects\Layui-`，因为 `main.py` 在这里）：

```bash
python -m uvicorn main:app --reload
```

## 3. 逐个拆开：是什么 + 对应什么

### 3.1 代码里的

| 写法                            | 是什么                                                            | 对应：效果 / 你学过的类似东西                                                                                                 |
| ------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `from fastapi import FastAPI` | 从装好的`fastapi` 包里拿出 `FastAPI` 类                       | 像 html 里先写`<script src="layui.js">`：先把工具拿进来，后面才能用                                                         |
| `app = FastAPI()`             | 用`FastAPI` 类造出一个应用（官方叫"实例"），存在变量 `app` 里 | 像`const table = layui.table`：拿到一个对象，后面都通过它调用。启动命令 `main:app` 里的 `app` 就是这个变量              |
| `@app.get(...)`               | 路径操作装饰器。`@` = 把下面的函数交给 `app.get` 登记         | 像`table.on("tool(studentTable)", 函数)`：现在只登记，不执行；有人访问才调用                                                |
| `.get`                        | 操作（HTTP 方法）。`get` = 拿数据                               | 地址栏打开网址发的就是 GET。以后还有`.post` 新增、`.put` 修改、`.delete` 删除                                           |
| `"/api/ping"`                 | 路径                                                              | 对应网址`http://127.0.0.1:8000/api/ping` 里的 `/api/ping`。前面加 `/api` 是习惯，表示"这是给程序用的数据接口，不是页面" |
| `def ping():`                 | 路径操作函数                                                      | 函数名自己起，和网址无关；网址只看装饰器里的路径                                                                              |
| `return {"ok": True}`         | 返回值。FastAPI 把它转成 JSON，作为响应体发回去                   | 浏览器看到`{"ok":true}`。注意 Python 的 `True` 变成了 JSON 的 `true`                                                    |

### 3.2 命令和地址里的

| 写法                  | 是什么                                                        | 对应                                                      |
| --------------------- | ------------------------------------------------------------- | --------------------------------------------------------- |
| `uvicorn`           | 服务器程序：一直开着，守在一个端口上等请求，收到就交给`app` | 终端不能关，关了网站就停。要停按`Ctrl + C`              |
| `python -m uvicorn` | 用当前环境的 python 运行 uvicorn                              | 比直接打`uvicorn` 稳：不会因为找不到命令而失败          |
| `main:app`          | `main.py` 文件里的 `app` 变量                             | 文件改名或变量改名，这里也要跟着改                        |
| `--reload`          | 保存`.py` 后自动重启                                        | 改 html 不用重启，刷新浏览器就行                          |
| `127.0.0.1`         | 本机地址：只有自己这台电脑能访问                              |                                                           |
| `:8000`             | 端口：像门牌号，uvicorn 守在 8000 号门                        |                                                           |
| `/docs`             | FastAPI 按你登记的接口自动生成的测试页面                      | 点接口 → Try it out → Execute，效果和浏览器直接打开一样 |

## 4. 结构树

```text
main.py
├── from fastapi import FastAPI        导入
├── app = FastAPI()                    创建应用（只写一次）
└── @app.get("/路径")                  登记：方法 + 路径
    def 函数名():                       有人访问时被调用
        return 字典 / 列表              变成 JSON 发回去

终端：python -m uvicorn main:app --reload
          │              │    │      └ 改 .py 自动重启
          │              │    └ app 变量
          │              └ main.py 文件
          └ 当前环境的 python 运行 uvicorn
```

## 5. 我实测过的现象（你做的时候对照）

| 你做                                              | 看到                                                            | 原因                                   |
| ------------------------------------------------- | --------------------------------------------------------------- | -------------------------------------- |
| 打开`/api/ping`                                 | `{"ok":true}`，终端多一行 `"GET /api/ping HTTP/1.1" 200 OK` | 找到了登记的函数；200 = 成功           |
| 打开`/api/pin`（拼错）                          | `{"detail":"Not Found"}`，终端里是 `404 Not Found`          | 没有登记这个路径                       |
| 函数里忘了写`return`                            | 浏览器显示`null`                                              | 函数没返回东西                         |
| 把`@app.get` 改成 `@app.post`，再用地址栏打开 | `{"detail":"Method Not Allowed"}`（405）                      | 路径对上了，方法不对：地址栏发的是 GET |
| 两个函数登记了同一个方法和路径                    | 永远调用写在前面的那个                                          | FastAPI 从上往下找，找到第一个就停     |

## 6. 一句话规则

**`@app.get("路径")` 是登记，不是调用；有人用 GET 访问这个路径时，FastAPI 调用下面的函数，把 `return` 的东西转成 JSON 发回去。**

## 8. 常见错误（先自查）

| 终端或浏览器里看到                                                     | 原因                                                                           |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `Error loading ASGI app. Could not import module "main"`             | 终端当前目录不是项目根目录，或文件名不是`main.py`                            |
| `Error loading ASGI app. Attribute "app" not found in module "main"` | `main.py` 里的变量不叫 `app`，或命令里的 `app` 拼错                      |
| `No module named 'fastapi'` 或 `No module named uvicorn`           | 终端最前面没有`(.venv)`：没进虚拟环境，见第 1 节                             |
| 提示`10048`、地址已被占用                                            | 另一个终端里服务器还开着。去那个终端按`Ctrl + C`，或启动时加 `--port 8001` |
| 终端里有`SyntaxError` / `IndentationError`                         | Python 写法或缩进错，看终端给出的行号                                          |
| 改了`main.py`，浏览器没变化                                          | 启动时没加`--reload`，或者没保存                                             |
