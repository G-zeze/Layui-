## 1. 页面的三个区域

```html
<head>
    <link rel="stylesheet" href="./layui-v2.13.9/layui/css/layui.css">
</head>
<body>
    <!-- 页面内容 -->

    <script src="./layui-v2.13.9/layui/layui.js"></script>
    <script>
        // 自己的 JS
    </script>
</body>
```

```text
head：引入 layui.css（让 layui-* 类有样式）
body
├── 页面内容（导航、卡片、表单）
└── 底部
    ├── 引入 layui.js（提供 JS 功能）
    └── 自己的 JS（写在内容之后）
```

**规则：** CSS 在 head，JS 在 body 最后，自己的 JS 在 `layui.js` 之后。

## 2. 导航

```html
<ul class="layui-nav">
    <li class="layui-nav-item layui-this"><a href="javascript:;">首页</a></li>
    <li class="layui-nav-item">
        <a href="javascript:;">管理</a>
        <dl class="layui-nav-child">
            <dd><a href="javascript:;">列表</a></dd>
        </dl>
    </li>
</ul>
```

```text
ul.layui-nav
└── li.layui-nav-item（选中项加 layui-this）
    ├── a：主项目
    └── dl.layui-nav-child：这个项目的子菜单
        └── dd → a
```

**规则：** 切换和下拉靠 JS 的 `element` 模块；`href` 要写 `javascript:;`（有 `:;`）。

## 3. 布局与卡片

```html
<div class="layui-container">
    <div class="layui-row layui-col-space15">
        <div class="layui-col-xs12 layui-col-md6">
            <div class="layui-card">
                <div class="layui-card-header">标题</div>
                <div class="layui-card-body">内容</div>
            </div>
        </div>
        <div class="layui-col-xs12 layui-col-md6"> ... </div>
    </div>
</div>
```

```text
container：页面主体
└── row.layui-col-space15：一横排（space15 = 列间距）
    └── col：这一列占几格（一行共 12 格）
        └── card
            ├── card-header：标题区
            └── card-body：内容区
```

| 写法              | 含义                         |
| ----------------- | ---------------------------- |
| `xs12`          | 窄屏占满 12 格（上下排列）   |
| `md6`           | 宽屏占 6 格（两个 md6 并排） |
| `md3 xs6`       | 宽屏 4 个一排，窄屏 2 个一排 |
| `md8` + `md4` | 宽屏 8:4 两列                |

**规则：** 列负责宽度，卡片负责外观；列放在行里，行放在容器里。

## 4. 表单：一项的写法

```html
<form class="layui-form">
    <div class="layui-form-item">
        <label class="layui-form-label" for="phone">联系电话</label>
        <div class="layui-input-block">
            <input type="text" id="phone" name="phone" class="layui-input">
        </div>
    </div>
</form>
```

```text
form.layui-form
└── div.layui-form-item        ← 每一项单独一个
    ├── label.layui-form-label  ← 在 input-block 外面，和它平级
    └── div.layui-input-block
        └── input / select
```

**规则：** `label for` = `input id`；`name` 是 `data.field` 里的键；标签类名是 `layui-form-label`。

### 下拉框

```html
<select name="classType" id="classType">
    <option value="">请选择</option>
    <option value="day">日间班</option>
    <option value="night">夜间班</option>
</select>
```

```text
select（name 提供键）
└── option value="程序读到的值"：用户看到的文字
```

**规则：** 下拉框要靠 JS `form.render()` 渲染。

### 日期框（和文本框一样，多一步绑定）

```html
<input type="text" id="enrollDate" name="enrollDate" class="layui-input">
```

```text
结构同文本框；再用 JS：laydate.render({ elem: "#enrollDate" })
```

**规则：** 日期框放进 `layui-input-block`，用 `id` 绑定日历。

### 按钮

```html
<button type="button" class="layui-btn" id="showBtn">普通按钮</button>
<button type="submit" class="layui-btn" lay-submit lay-filter="saveClass">提交按钮</button>
<button type="reset" class="layui-btn layui-btn-primary">重置</button>
```

```text
type="button"：普通按钮，靠 JS 点击事件
type="submit" + lay-submit + lay-filter：提交按钮，靠 form.on
type="reset"：重置，什么都不用写
```

**规则：** `layui-btn` 是基础类，`layui-btn-primary` 是灰色次要按钮。

## 5. 选项卡

```html
<div class="layui-tab">
    <ul class="layui-tab-title">
        <li class="layui-this">标题一</li>
        <li>标题二</li>
    </ul>
    <div class="layui-tab-content">
        <div class="layui-tab-item layui-show">内容一</div>
        <div class="layui-tab-item">内容二</div>
    </div>
</div>
```

```text
div.layui-tab
├── ul.layui-tab-title       ← 标题区
│   └── li（默认项加 layui-this）
└── div.layui-tab-content    ← 内容区，和标题区平级
    └── div.layui-tab-item（默认项加 layui-show）
```

**规则：** 标题和内容靠顺序对应；两个"默认"标在同一项；切换靠 `element` 模块。

## 6. 脚本骨架

```javascript
layui.use(["element", "form", "layer", "laydate"], function () {
    const element = layui.element;
    const form = layui.form;
    const layer = layui.layer;
    const laydate = layui.laydate;

    form.render();
    laydate.render({ elem: "#enrollDate" });

    // 点击事件、表单提交写在这里面
});
```

```text
layui.use([模块名...], 回调函数)
└── 回调函数里
    ├── 用 const 取出每个模块
    ├── form.render()：渲染下拉框
    ├── laydate.render()：绑定日期框
    └── 登记点击事件 / 提交事件
```

**规则：** 用到哪个模块，数组里就写哪个；所有代码写在回调函数**里面**。

## 7. 普通按钮点击

```javascript
const showBtn = document.querySelector("#showBtn");
showBtn.addEventListener("click", function () {
    layer.msg("你点了按钮");
});
```

```text
HTML 按钮有 id
→ querySelector("#id") 找到按钮
→ addEventListener("click", 函数) 登记
→ 用户点击
→ 浏览器调用函数
```

**规则：** 要等点击才做的事，写在函数**里面**。

## 8. 表单提交

```javascript
function saveClass(data) {
    console.log(data.field);
    layer.msg("已收到数据");
    return false;
}
form.on("submit(saveClass)", saveClass);
```

```text
按钮 lay-filter="saveClass"
          ↕ 名字一致
form.on("submit(saveClass)", 函数)

用户点提交 → 先验证（lay-verify）→ 通过 → Layui 调用函数
函数里：data.field 是表单数据，return false 阻止刷新
```

| 属性                      | 作用                       |
| ------------------------- | -------------------------- |
| `lay-verify="required"` | 这一项必填                 |
| `lay-submit`            | 这是提交按钮               |
| `lay-filter="名"`       | 提交按钮的名字             |
| `data.field`            | 键来自`name`，值来自输入 |
| `return false`          | 阻止浏览器默认提交         |

**规则：** `return false` 写在提交函数的最外层。

## 9. layer 四种弹层

```javascript
layer.msg("通知");                      // 几秒后自己消失
layer.alert("提示");                    // 点"确定"才关
layer.confirm("确定吗?", function (index) {   // 点"确定"才执行
    layer.msg("已确定");
    layer.close(index);
});
layer.open({
    type: 1,
    title: "标题",
    content: "<div class='layui-padding-3'>内容</div>",
    area: ["400px", "200px"]
});
```

```text
msg      通知，自动消失
alert    只有"确定"
confirm  确定 / 取消（确定函数里的事，点确定才执行；取消不调用）
open     自定义窗口，type:1 表示内容是自己写的 HTML
```

**规则：** `index` 是弹层编号，`layer.close(index)` 关掉它；confirm 点确定后要自己关。

## 10. 确认后再保存（confirm 套提交）

```javascript
function saveClass(data) {
    layer.confirm("确定保存吗?", function (index) {
        console.log(data.field);
        layer.close(index);
        layer.msg("已收到数据");
    });
    return false;
}
```

```text
saveClass 被调用
├── layer.confirm(...)：弹确认框，把"确定函数"交给 layer 保管（不执行）
└── return false：马上执行，结束 saveClass

用户点"确定" → layer 调用确定函数 → 里面的内容全部执行
用户点"取消" → 确定函数没有被调用
```

**规则：** 括号里的函数点击后才执行；括号外的语句马上执行；`return false` 在外层。

## 11. 逗号、分号、引号

```javascript
layer.open({
    type: 1,           // 后面还有 → 逗号
    title: "标题",      // 后面还有 → 逗号
    content: "..."     // 最后一项 → 不加
});                    // 语句结束 → 分号
```

```text
逗号隔开"同一层里的并列项"：对象的键值对 / 括号里的参数 / 数组的元素
最后一项后面不加；语句写完用分号
引号：外面双引号，里面的 HTML 属性用单引号
```


```javascript
document.querySelector("#saveBtn");     // id 用 #
```

## 13. 出问题先查这里

| 症状                   | 原因                                             |
| ---------------------- | ------------------------------------------------ |
| 样式完全没生效         | class 拼错：`calss`、`layui-tab-itme`        |
| 列之间没间距           | 应为`layui-col-space15`                        |
| 标签没对齐             | 应为`layui-form-label`（不是 `layui-label`） |
| 标签和输入框挤一起     | `label` 被放进了 `layui-input-block`         |
| 确认框一闪就没了       | `layer.msg` 写在 `confirm` 括号外面          |
| 提交后页面刷新         | 没写`return false` 或写进了里层函数            |
| 导航/选项卡不动        | `use` 数组里没有 `"element"`                 |
| `xxx is not defined` | 模块没写进数组，或`const x = layui.x` 漏了     |

**排错三步：**

1. F12 → Console，看红字提示。
2. F12 → 左上角"选择元素"，点有问题的地方，看它**实际**有哪些 class。
3. 对照本页结构树，从外层往里层逐层找。
