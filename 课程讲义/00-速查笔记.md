# 一、页面基础

## 1.1 HTML 元素、属性

```html
<button class="layui-btn" id="startButton">开始学习</button>
```

```text
button            标签（元素）：开始标签 <button>，结束标签 </button>，中间是显示的文字
class="layui-btn" 这一类：让 CSS 找到它（可以写多个，空格隔开）
id="startButton"  页面内唯一的名字：让 JS 找到它
```

**规则：** `class` 管"属于哪一类"，`id` 管"具体是哪一个"。按钮变绿是 `layui.css` 里写好了 `.layui-btn` 的样子，不是 class 自己产生的。

## 1.2 页面的三个区域

```html
<head>
    <link rel="stylesheet" href="./layui-v2.13.9/layui/css/layui.css">
</head>
<body class="layui-bg-gray">
    <!-- 页面内容：导航、卡片、表单 -->

    <script src="./layui-v2.13.9/layui/layui.js"></script>
    <script>
        // 自己的 JS
    </script>
</body>
```

```text
head：引入 layui.css（让 layui-* 类有样式）
body
├── 页面内容
└── 底部
    ├── 引入 layui.js（提供 layui 对象和各模块）
    └── 自己的 JS（必须在 layui.js 之后）
```

**规则：** CSS 在 head，JS 在 body 最后。先引入、后使用，否则报 `layui is not defined`。

## 1.3 CDN 与本地路径

```html
<!-- CDN -->
<link href="//unpkg.com/layui@2.13.9/dist/css/layui.css" rel="stylesheet">
<script src="//unpkg.com/layui@2.13.9/dist/layui.js"></script>
<!-- 本地 -->
<link href="./layui-v2.13.9/layui/css/layui.css" rel="stylesheet">
<script src="./layui-v2.13.9/layui/layui.js"></script>
```

```text
./   从当前 HTML 所在文件夹开始
```

**规则：** CDN 要联网；本地路径跟着 HTML 位置走，移动 HTML 后路径要改。CSS 失败＝按钮变朴素；JS 失败＝`layui is not defined`。

## 1.4 `div` 和 `span`

```html
<div class="layui-card-body">
    今日新增：<span class="layui-font-20">12</span> 人
</div>
```

```text
div   块级容器：独占一整行，用来分区、搭结构
span  行内容器：只占内容那么宽，不换行，用来包住一行文字里的某一小段
两者本身都没有含义和样式，全靠加上去的 class / id 才有作用
```

**规则：** 要"分区"用 `div`；要在一句话中间单独给几个字加样式（放大、变色），用 `span`。

# 二、页面布局与组件

## 2.1 导航

```html
<ul class="layui-nav">
    <li class="layui-nav-item layui-this"><a href="javascript:;">首页</a></li>
    <li class="layui-nav-item">
        <a href="javascript:;">学生管理</a>
        <dl class="layui-nav-child">
            <dd><a href="javascript:;">学生列表</a></dd>
        </dl>
    </li>
</ul>
```

```text
ul.layui-nav
└── li.layui-nav-item（选中项加 layui-this）
    ├── a：主项目
    └── dl.layui-nav-child：属于这个项目的子菜单（写在它所属的 li 里面）
        └── dd → a
```

**规则：** 高亮/下拉靠 JS 的 `element` 模块；`href` 写 `javascript:;`（有 `:;`），否则点了会跳转刷新。

## 2.2 栅格 + 卡片

```html
<div class="layui-container">
    <div class="layui-row layui-col-space15">
        <div class="layui-col-xs12 layui-col-md6">
            <div class="layui-card">
                <div class="layui-card-header">标题</div>
                <div class="layui-card-body">内容</div>
            </div>
        </div>
        <div class="layui-col-xs12 layui-col-md6"> ... </div>
    </div>
</div>
```

```text
container：页面主体
└── row.layui-col-space15：一横排（space15 = 列间距 15px，写在行上）
    └── col：这一列占几格（一行共 12 格）
        └── card
            ├── card-header：标题区
            └── card-body：内容区
```

| 写法              | 含义                         |
| ----------------- | ---------------------------- |
| `xs12`          | 窄屏占满 12 格（上下排列）   |
| `md6`           | 宽屏占 6 格（两个 md6 并排） |
| `md4` ×3       | 宽屏三等分                   |
| `md3 xs6`       | 宽屏 4 个一排，窄屏 2 个一排 |
| `md8` + `md4` | 宽屏 8:4 两列                |

**规则：** 列管宽度，卡片管外观；列放行里，行放容器里。`xs`/`md` 是屏幕宽度级别，不是设备名；同时写 `xs12 md4` 才把窄屏、宽屏两种情况都说清楚。

## 2.3 选项卡 layui-tab

```html
<div class="layui-tab">
    <ul class="layui-tab-title">
        <li class="layui-this">标题一</li>
        <li>标题二</li>
    </ul>
    <div class="layui-tab-content">
        <div class="layui-tab-item layui-show">内容一</div>
        <div class="layui-tab-item">内容二</div>
    </div>
</div>
```

```text
div.layui-tab
├── ul.layui-tab-title       ← 标题区
│   └── li（默认项加 layui-this）
└── div.layui-tab-content    ← 内容区，和标题区平级
    └── div.layui-tab-item（默认项加 layui-show）
```

**规则：** 标题和内容靠**顺序**对应；两个"默认"标在同一项；切换靠 `element` 模块（`use` 数组里要有 `"element"`，变量用不用都要写）。

## 2.4 按钮：基础类 + 修饰类

```html
<div class="layui-btn-container">
    <button class="layui-btn">新增学生</button>
    <button class="layui-btn layui-btn-normal">编辑学生</button>
    <button class="layui-btn layui-btn-danger layui-btn-sm">删除学生</button>
</div>
```

```text
基础类（layui-btn） + 颜色类 + 尺寸类，全写在同一个 class 里，空格隔开
颜色：primary 朴素/灰 · normal 蓝 · warm 暖色 · danger 危险红
尺寸：lg 大 · sm 小 · xs 迷你
形状：radius 圆角 · fluid 撑满父容器宽度
layui-btn-container：一组按钮的容器（管间距）
```

**规则：** 修饰类不能单独用，必须带 `layui-btn`。红色不等于安全，危险操作仍要 `confirm` 确认。

## 2.5 常用工具类（已在本地 layui.css 核实）

| 类名                                  | 作用                                           |
| ------------------------------------- | ---------------------------------------------- |
| `layui-bg-gray`                     | 灰色背景（常放 body 上，让白色卡片更突出）     |
| `layui-margin-1…5`                 | 外边距 4 / 8 / 16 / 32 / 48 px                 |
| `layui-padding-1…5`                | 内边距，同上档位（`layui-padding-3` = 16px） |
| `layui-font-12` / `layui-font-20` | 字号 12 / 20 px                                |
| `layui-font-gray`                   | 灰色文字                                       |
| `layui-text`                        | 文字排版（段落、链接样式）                     |
| `layui-badge`                       | 小徽标                                         |
| `layui-elem-quote`                  | 引用块                                         |

**规则：** 不存在的类（如 `layui-margin-15`、`layui-mt-3`）不会报错，只是没效果——写之前对照这张表或查 `layui.css`。

# 三、表单

## 3.1 先认识纯 HTML 表单（没有 Layui 时）

```html
<form>
    <label for="studentName">学生姓名</label>
    <input type="text" id="studentName" name="studentName" required>
    <button type="submit">保存学生</button>
</form>
```

```text
点击 type="submit" 的按钮
→ 浏览器检查 required
→ 收集所有带 name 的控件
→ 按默认方式提交，页面跳转/刷新（地址栏出现 ?studentName=...）
```

| 属性            | 负责什么                                          |
| --------------- | ------------------------------------------------- |
| `type="text"` | 文本输入框                                        |
| `id`          | 在页面中标识这个控件（给 label 的 for、给 JS 找） |
| `name`        | 提交时的字段名（以后是`data.field` 的键）       |
| `required`    | 浏览器原生必填（不是 Layui 的`lay-verify`）     |

**规则：** 默认提交会刷新页面，所以 Layui 里才需要 `return false`。

## 3.2 Layui 表单一项的写法

```html
<form class="layui-form">
    <div class="layui-form-item">
        <label class="layui-form-label" for="phone">联系电话</label>
        <div class="layui-input-block">
            <input type="text" id="phone" name="phone" class="layui-input"
                   lay-verify="required" placeholder="请输入联系电话">
        </div>
    </div>
</form>
```

```text
form.layui-form
└── div.layui-form-item        ← 每一项单独一个
    ├── label.layui-form-label  ← 在 input-block 外面，和它平级
    └── div.layui-input-block
        └── input / select
```

**规则：** `label for` = `input id`；`name` 是 `data.field` 里的键；标签类名是 `layui-form-label`（不是 `layui-label`）；`label` 放进 `input-block` 会挤在一起。

## 3.3 下拉框

```html
<select name="classType" id="classType">
    <option value="">请选择</option>
    <option value="day">日间班</option>
    <option value="night">夜间班</option>
</select>
```

```text
select（name 提供键）
└── option value="程序读到的值"：用户看到的文字
```

**规则：** 用户看到"日间班"，程序读到 `day`。原生下拉要靠 `form.render()` 换成 Layui 外观。

## 3.4 日期框

```html
<input type="text" id="enrollDate" name="enrollDate" class="layui-input" placeholder="请选择日期">
```

```text
结构同文本框，多一步 JS 绑定：laydate.render({ elem: "#enrollDate" })
```

**规则：** 日期框放进 `layui-input-block`；必须有 `id`；占位文字写"请选择"。

## 3.5 三种按钮

```html
<button type="button" class="layui-btn" id="showBtn">普通按钮</button>
<button type="submit" class="layui-btn" lay-submit lay-filter="saveClass">提交</button>
<button type="reset" class="layui-btn layui-btn-primary">重置</button>
```

```text
type="button"                         普通按钮，靠 JS 点击事件
type="submit" + lay-submit + lay-filter  提交按钮，靠 form.on
type="reset"                          重置，什么都不用写
```

**规则：** `type="submit"` 告诉**浏览器**这是提交；`lay-submit` 告诉 **Layui** 这是提交——两个都要。`lay-submit` 是单属性，不写值。没有 `lay-submit`：验证不起作用，页面直接刷新。

## 3.6 提交按钮的属性分工

| 属性                      | 作用                                                            |
| ------------------------- | --------------------------------------------------------------- |
| `lay-verify="required"` | 这一项必填（写在控件上）；只有按钮带`lay-submit` 才会触发验证 |
| `lay-submit`            | 这是提交按钮                                                    |
| `lay-filter="名"`       | 提交按钮的名字，`form.on` 靠它找到                            |
| `id`                    | 与提交无关，给 JS 的`querySelector` 用                        |

# 四、脚本基础

## 4.1 脚本骨架

```javascript
layui.use(["element", "form", "layer", "laydate"], function () {
    const element = layui.element;
    const form = layui.form;
    const layer = layui.layer;
    const laydate = layui.laydate;

    form.render();
    laydate.render({ elem: "#enrollDate" });

    // 点击事件、表单提交写在这里面
});
```

```text
layui.use([模块名...], 回调函数)
└── 回调函数里
    ├── 用 const 取出每个模块
    ├── form.render()：渲染下拉框
    ├── laydate.render()：绑定日期框
    └── 登记点击事件 / 提交事件
```

**规则：** 用到哪个模块，数组里就写哪个；所有代码写在回调函数**里面**。

## 4.2 use 的两种写法

```javascript
layui.use(function () { ... });                       // 简写：省略模块数组
layui.use(["layer", "form"], function () { ... });    // 完整：明确列出模块
```

**规则：** 第一个参数是模块名数组（`[]`），第二个是准备好之后执行的回调。入门示例用简写，正式页面用完整写法。

## 4.3 变量：const / let / var

```javascript
const layer = layui.layer;   // 不重新赋值 → 默认用 const
let count = 0;               // 以后要改 → let
var old = 1;                 // 旧写法：能看懂，自己不用
```

**规则：** 默认 `const`，需要重新赋值才用 `let`，新代码不用 `var`。`const layer = layui.layer` 没有调用函数，只是给模块对象起个短名字。

## 4.4 对象 · 函数 · 方法 · 调用 · 模块

```text
变量：给一个值起名字
对象：把相关的数据和功能装在一起
函数：一段可以执行的代码
方法：放在对象里的函数  →  对象.方法()
调用：加 () 才真正执行
模块：围绕一种功能整理好的一包代码，通常提供对象和方法

layui
├── layer（弹层模块）   → msg / alert / confirm / open / close
├── form（表单模块）    → render / on
├── laydate（日期模块） → render
└── element（导航、选项卡）
```

```text
layui.element      获取属性，没有调用
layer.msg          拿到函数本身，没有调用
layer.msg("你好")  调用 msg 方法
sayHello           函数本身（一张没执行的清单）
sayHello()         现在执行
```

**规则：** 判断有没有调用，只看函数名后面有没有 `()`。点号的意思是"用对象里的东西"。

## 4.5 参数与配置对象

```javascript
layer.msg("保存成功", {
    icon: 1,
    time: 2000
});
```

```text
第一个参数："保存成功"          显示什么文字
第二个参数：{ icon: 1, time: 2000 }  配置对象（键: 值）
icon  图标类型    time  显示时长（毫秒，2000 = 2 秒）
```

**规则：** 用 `对象.方法(参数)` 调用；配置写成 `{键: 值, 键: 值}`；`{}` 在 `function` 后面是代码块，作为参数且里面是 `键: 值` 才是对象。

## 4.6 回调函数、匿名函数

```text
匿名函数：没有名字的函数
回调函数：被交给别人、以后由别人调用的函数
同一个函数可以既是匿名的又是回调的
```

| 谁调用 | 什么时候           | 代码                                             |
| ------ | ------------------ | ------------------------------------------------ |
| Layui  | 模块准备好之后     | `layui.use([...], function () {...})`          |
| 浏览器 | 用户点击之后       | `addEventListener("click", function () {...})` |
| Layui  | 验证通过并提交之后 | `form.on("submit(名)", 函数)`                  |
| layer  | 用户点"确定"之后   | `layer.confirm("...", function (index) {...})` |

**规则：** 把函数**交出去**不写括号（`form.on("submit(x)", save)`）；写了括号（`save()`）就变成立刻执行，把结果交出去。

## 4.7 执行顺序与作用范围（最重要）

```text
交给别人的函数（括号里的 function）：先保管，等触发才执行
写在括号外面的语句：读到就马上执行
```

```text
【页面打开：自上而下】
1. head 加载 layui.css
2. body 创建页面元素（此时元素才存在）
3. layui.js 加载 → 得到 layui
4. 自己的 <script>：layui.use(...) 只是登记"准备好后请调用我"
5. Layui 准备好 → 调用 use 回调，里面自上而下：
   取模块 → form.render()（执行）→ querySelector（执行）
   → addEventListener（只登记）→ 定义函数（只保存）→ form.on（只登记）
【之后：等用户操作】
6. 点按钮 → 浏览器调用点击函数
7. 点提交 → Layui 验证 → 通过才调用提交函数
```

```text
layui.use(..., function () {                       范围 A
    const form = layui.form;                       在 A 里
    btn.addEventListener("click", function () {    范围 B（在 A 里面）
        layer.msg("...");                          只在 B 里，点击后才执行
    });
    function save(data) {...}                      在 A 里，和 B 并排
    form.on("submit(x)", save);                    在 A 里，页面一打开就登记
});
```

**规则：** 里面能看到外面，外面看不到里面；写在哪个范围，就在那个范围的时机执行。**提交函数和 `form.on` 不能写进点击函数里。** 阅读时找每个 `function ... {` 配对的 `}`，由外向内读。

# 五、事件与数据

## 5.1 普通按钮点击

```javascript
const showBtn = document.querySelector("#showBtn");
showBtn.addEventListener("click", function () {
    layer.msg("你点了按钮");
});
```

```text
HTML 按钮有 id
→ querySelector("#id") 找到按钮
→ addEventListener("click", 函数) 登记
→ 用户点击
→ 浏览器调用函数
```

**规则：** 要等点击才做的事，写在函数**里面**；`querySelector` 的参数是选择器，id 前面要有 `#`。

## 5.2 表单提交

```javascript
function saveClass(data) {
    console.log(data.field);
    layer.msg("已收到数据");
    return false;
}
form.on("submit(saveClass)", saveClass);
```

```text
按钮 lay-filter="saveClass"
          ↕ 名字一致（字符串，不是变量）
form.on("submit(saveClass)", 函数)

用户点提交 → 先验证（lay-verify）→ 不通过：提示后结束，不调用函数
                                → 通过：收集数据，调用函数
函数里：data.field 是表单数据，return false 阻止刷新
```

**规则：** `return false` 写在提交函数的最外层（`return` 只结束它所在的那个函数）。同一个过滤名再登记一次会覆盖上一次。

## 5.3 data 与 data.field

```javascript
data = { elem: 被点的按钮, form: 所在的 form 元素, field: { studentName: "张三", gender: "male" } }
```

**规则：** `field` 的键来自 `name`（不是 `id`），值来自输入文字或选中 `option` 的 `value`；没有 `name` 的控件不会被收集。以后用 `fetch` 发给 FastAPI，`name` 要和后端字段一一对应。

## 5.4 form.render()

```text
做什么：把原生 select（以及 checkbox、radio）换成 Layui 外观，原控件仍在，数据仍从它读
不做什么：不提交、不验证、不收集数据
何时再调用：JS 动态添加控件或改了下拉选项之后
```

**规则：** 注释掉它，下拉框就变回浏览器原生样子。

# 六、弹层与日期

## 6.1 layer 四种弹层

```javascript
layer.msg("通知");                          // 几秒后自己消失
layer.alert("提示");                        // 点"确定"才关
layer.confirm("确定吗?", function (index) { // 点"确定"才执行
    layer.msg("已确定");
    layer.close(index);
});
layer.open({
    type: 1,
    title: "标题",
    content: "<div class='layui-padding-3'>内容</div>",
    area: ["400px", "200px"]
});
```

```text
msg      通知，自动消失
alert    只有"确定"
confirm  确定 / 取消（取消不调用函数）
open     自定义窗口
```

**规则：** `index` 是弹层编号，`layer.close(index)` 关掉它；confirm 点确定后要自己关。

## 6.2 layer.open 的 type

| type  | 含义                                                            |
| ----- | --------------------------------------------------------------- |
| `0` | 信息框（默认）                                                  |
| `1` | 页面层：`content` 是自己写的 HTML                             |
| `2` | iframe：`content` 被当成**网址**（写文字会乱码/打不开） |
| `3` | 加载中转圈（需要自己关）                                        |

**规则：** `content` 用双引号，里面的 HTML 属性用单引号。点击按钮弹出说明窗口的完整连接：按钮 `id` → `querySelector` → `addEventListener` → `layer.open`。

## 6.3 确认后再保存（confirm 套提交）

```javascript
function saveClass(data) {
    layer.confirm("确定保存吗?", function (index) {
        console.log(data.field);
        layer.close(index);
        layer.msg("已收到数据");
    });
    return false;
}
```

```text
saveClass 被调用
├── layer.confirm(...)：弹确认框，把"确定函数"交给 layer 保管（不执行）
└── return false：马上执行，结束 saveClass

用户点"确定" → layer 调用确定函数 → 里面的内容全部执行
用户点"取消" → 确定函数没有被调用
```

**规则：** 括号里的函数点击后才执行，括号外的语句马上执行；`layer.msg` 写在 confirm 外面会立刻把确认框关掉（打开新的 type 0 弹层会先关掉已有对话框）。

## 6.4 laydate 日期

```javascript
// 1) 输入框有 id   2) use 数组加 "laydate"   3) 绑定
laydate.render({ elem: "#enrollDate", type: "date", format: "yyyy-MM-dd" });
```

**规则：** `elem` 写法同 `querySelector`，`#` 不能漏；`type`、`format` 不写也默认是日期 `yyyy-MM-dd`；日期框可加 `lay-verify="required"`。

| `layer is not defined`                          | `use` 数组没写 `"layer"` 或漏了 `const layer = layui.layer;`                                                   |
| 表格整个没出现                                    | `use` 数组没写 `"table"`、`elem` 漏了 `#` 或与 `id` 不一致、`cols` 少了一层 `[ ]`                      |
| `Cannot read properties of null (reading 'value')` | `querySelector("#…")` 没找到元素：id 拼错或大小写不一致（`addId` ≠ `addID`） |

| 页面打开后按钮全没反应，Console 有一条红字 | `layui.use` 里某行出错，后面的代码都没执行；先修这条红字 |

# 十、table 数据表格

## 10.1 原生表格 ↔ table.render 对照

```html
<table>
  <thead>
    <tr><th>学号</th><th>姓名</th></tr>
  </thead>
  <tbody>
    <tr><td>001</td><td>张三</td></tr>
    <tr><td>002</td><td>李四</td></tr>
  </tbody>
</table>
```

```text
table
├── thead → tr → th, th      表头区：每个 th 是一列的表头      ←→  cols（有哪几列）
└── tbody → tr → td, td      数据区：每个 tr 是一行，每个 td 是一格 ←→  data（有哪几行）
```

**规则：** `tr` 是一行，`th` 是表头格，`td` 是数据格；`table.render` 就是让 Layui 按 `cols` 和 `data` 替你写出这些标签。

## 10.2 table.render 最小写法

```html
<table id="studentTable"></table>
```

```js
layui.use(["table"], function(){
    const table = layui.table;
    table.render({
        elem: "#studentTable",
        cols: [[
            {field:"studentId", title:"学号"},
            {field:"studentName", title:"姓名"}
        ]],
        data: [
            {studentId:"001", studentName:"张三"},
            {studentId:"002", studentName:"李四"}
        ]
    });
});
```

```text
table.render(配置对象)
├── elem : "#id"          画在哪个 <table id="…"> 里（和 laydate 的 elem 一样，# 不能漏）
├── cols : [[ 列, 列 ]]   表头区：外层 [] 是表头的行，内层 [] 是这一行的各列
│     └── {field:"键名", title:"表头文字"}
│           ├── title ：该列表头显示的文字（对应 <th> 里的字）
│           └── field ：该列的值去每条数据里找哪个键
└── data : [ {对象}, {对象} ]   数据区：一个对象 = 一行；对象里的值 = 这一行的格子
```

**规则：** 每一格的值 = 这一行的对象里，键名等于这一列 `field` 的那个值；**`field` 必须和 `data` 里的键名一模一样**，找不到这一格就是空白。

## 10.3 elem 是谁的、写在哪

```text
HTML 标签里：id、name、class、for          HTML 自己的属性
HTML 标签里：lay-submit、lay-filter         Layui 规定的属性（标签里）
JS 配置对象里：elem、cols、data、title、field   Layui 组件的配置项（只在对应的 render({}) 里有效）
```

**规则：** 看它写在哪：标签里的是属性，JS 配置对象里的是配置项；`id` 是元素的名字，`elem:"#id"` 是通过这个名字找元素。

## 10.4 分页 page / limit

```js
table.render({
    elem: "#studentTable",
    cols: [[ … ]],
    data: [ … ],
    page: true,
    limit: 5
});
```

```text
table.render({ … })
├── page  : true     开启分页：表格下方出现分页条
└── limit : 5        每页显示几条；页数 = 总条数 ÷ 每页条数，向上取整（8 条、limit 5 → 2 页）
```

**规则：** `page`、`limit` 和 `elem`、`cols`、`data` 同级，都写在 `render({ })` 里；Layui 按 `limit` 自动把 `data` 分页，不用自己拆数据；`data` 行末尾要有逗号，最后一项不加。

## 10.5 排序 sort

```js
cols: [[
    {field:"studentId", title:"学号", sort:true},
    {field:"studentName", title:"姓名"},
    {field:"studentClass", title:"班级", sort:true}
]],
```

```text
cols → 某一列的对象 {field, title, sort:true}
└── sort:true   这一列表头出现升降序箭头；点箭头在升序 / 降序 / 还原之间切换
```

**规则：** `sort` 写在**某一列的对象里**，只管这一列；`page`、`limit` 写在 `render({ })` 最外层，管整张表。排序比较的方式：数字按**数值大小**；文字按 **Unicode 字符编码**逐字比（不是拼音、不是笔画，汉字排出来不是"一二三"顺序）；数字和文字混在一列时数字在前。

## 10.6 自定义列内容 templet

```js
{field:"studentGender", title:"性别", templet:function(d){
    return d.studentGender + "生";
}}
```

```text
cols → 某一列的对象
└── templet : function(d){ return 要显示的内容; }
      ├── d      这一行的对象（Layui 画到这一行时传进来；名字可以自己起，但要前后一致）
      └── return 返回什么，这一格就显示什么（忘了 return → 空白）
```

**规则：** `templet` 的函数不是你调用的，是 Layui 画**每一行**时调用一次（第一次画表、翻页、排序重画都会调用），`d` 是当前这一行的对象；和 `form.on` 回调里的 `data` 一样，都是 Layui 调用函数时传进来的参数。注意：`render` 里的 `data:[…]` 是你交给 Layui 的整个数组，`d` 是数组里的一个对象。

## 10.7 操作列按钮（只显示）

```js
{title:"操作", templet:function(d){
    return '<a class="layui-btn layui-btn-xs" lay-event="edit">编辑</a> <a class="layui-btn layui-btn-xs layui-btn-danger" lay-event="delete">删除</a>';
}}
```

```text
cols → 一列 {title:"操作", templet:function(d){ return 'HTML 字符串'; }}
├── 没有 field      这一列的内容不是 data 里的某个键，不需要去取值
├── 返回的 HTML      每行都画出这两个按钮
│     ├── class="layui-btn layui-btn-xs"   基础按钮类 + 小尺寸；红色用 layui-btn-danger
│     └── lay-event="edit"                  给"点击事件"用的标记（名字自己起，下一步用它区分点了哪个）
└── 外层用单引号 '…'，里面的属性用双引号 "…"，两种引号不冲突
```

**规则：** `field` 的作用是"去 data 里取哪个键的值"；操作列内容是自己写的，不读 `data`，所以不写 `field`。`lay-event` 只是标记，真正让点击有反应要靠 `table.on("tool(…)")`（见下一节）。

## 10.8 行事件：点操作列按钮做事

```html
<table id="studentTable" lay-filter="studentTable"></table>
```

```js
table.on("tool(studentTable)", function(obj){
    if(obj.event === "edit"){
        layer.msg("编辑" + obj.data.studentName);
    }else if(obj.event === "delete"){
        layer.msg("删除" + obj.data.studentName);
    }
});
```

```text
① <table lay-filter="名字">             表格元素起名
② table.on("tool(名字)", function(obj){})  名字要和 ① 一致；点到带 lay-event 的元素时，Layui 调用这个函数
③ <a lay-event="edit">                  按钮上的标记，对应 obj.event
obj
├── obj.event   点的是哪个按钮（lay-event 的值）
├── obj.data    这一行的数据对象（和 templet 里的 d 同类）
├── obj.del()   把这一行从页面上删掉
└── obj.update({…})  修改这一行
```

**规则：** `lay-event` 只是名字牌；Layui 在 `table.render` 时给整个表格挂了点击监听，点到带 `lay-event` 的元素就触发 `tool(lay-filter 的值)`，把"点的哪个按钮、哪一行"装进 `obj` 交给你的函数；`obj`（表格行事件）装的是"点了哪一行的哪个按钮"，`form.on` 里的 `data` 装的是"表单填了什么"，都是 Layui 调用函数时传入。要用 `layer`，`use` 数组里要写 `"layer"` 并 `const layer = layui.layer;`。

## 10.9 删除一行：confirm + obj.del()

```js
else if(obj.event === "delete"){
    layer.confirm("确定要删除" + obj.data.studentName + "吗?", function(index){
        obj.del();
        layer.close(index);
        layer.msg("已删除" + obj.data.studentName);
    });
}
```

```text
点删除 → layer.confirm(提示文字, 确定时执行的函数(index){ … })
              ├── obj.del()          把这一行从页面上拿掉（不改 data，不重算分页）
              ├── layer.close(index) 关确认框
              └── layer.msg(…)       提示（写在 confirm 括号里面）
```

**规则：** `obj.del()` 只是把页面上这一行去掉，`render` 里的 `data` 数组没变：翻页重画或刷新页面，这一行会回来，分页条的页数也不变；要真的删掉，得改数据数组再 `reloadData`（见 10.13）。

## 10.10 选中行：复选框列 + checkStatus

```js
{type:"checkbox"},      // 写在 cols 里，当作一列
```

```js
document.querySelector("#showChecked").addEventListener("click", function(){
    const status = table.checkStatus("studentTable");
    layer.msg("已选中" + status.data.length + "条数据");
});
```

```text
table.checkStatus("表格id")      主动查询：现在谁被勾选了（快照，之后再勾不会自动更新）
└── status.data                被勾选的行组成的数组；.length 是条数
```

**规则：** `checkStatus` 是你的代码执行到那一行才去问一次，不是事件通知；带分页的静态数据只统计**当前这一页**（翻页后再点，条数从新这一页算）；登记 click 要写在 `table.on` 函数的外面。

## 10.11 换数据重画：table.reloadData + 数组 filter

```js
const girls = students.filter(function(s){
    return s.studentGender === "女";
});
table.reloadData("studentTable", {
    data: girls,
    page: {curr: 1}
});
```

```text
students.filter(函数)            数组对每个元素调用一次函数（s = 当前这个学生）；return true 留下、false 丢掉；返回新数组，原数组不变
table.reloadData("表格id", {…})
├── 第 1 个参数                 表格 id，不带 #（和 checkStatus 一样）
├── data: 新数组                换成这份数据；表头 cols 不用再写
└── page: {curr: 1}             回到第 1 页
```

**规则：** `reloadData` 不重建表头，只用新的 `data` 重画数据行，也不修改你原来的数组；换了一份条数不同的数据，要同时写 `page:{curr:1}`，否则停在原页码，那一页没数据就显示空白。"搜索、筛选、真删除、编辑后刷新"都是同一个动作：**准备新数组 → `reloadData`**。

## 10.12 搜索框：输入框 .value + includes

```js
const keyword = document.querySelector("#keyword").value;   // 点击时才读
const result = students.filter(function(s){
    return s.studentName.includes(keyword);
});
table.reloadData("studentTable", {data: result, page: {curr: 1}});
```

```text
输入框.value        取输入框当前内容(字符串)；必须写在点击函数里，点的那一刻才读
字符串.includes(x)  包含 x 返回 true，否则 false；x 为空串时每个名字都包含 → 显示全部
filter + includes   搜索 = 留下名字包含关键字的人
return              漏写 return，filter 得到空数组 → 表格暂无数据
```

**规则：** 搜索 = 点击时读 `.value` → `filter` 出新数组 → `reloadData`（带 `page:{curr:1}`）。

## 10.13 真删除：改数组 + reloadData

```js
layer.confirm("确定要删除" + obj.data.studentName + "吗?", function(index){
    students = students.filter(function(s){
        return s.studentId !== obj.data.studentId;     // 留下学号不同的人
    });
    table.reloadData("studentTable", {data: students, page: {curr: 1}});
    layer.close(index);
});
```

```text
let students = […]      要整个换成新数组的变量用 let；const 重新赋值会报 Assignment to constant variable
!==                     不等于
reloadData 不写 page    停在原页码；末页被删空时显示"暂无数据"、页码回不去 → 写 page:{curr:1}
数据会变的数组(如 girls)  放进点击函数里现算，不要在函数外提前算好
```

**规则：** 真删除 = 改数据数组（`filter` 去掉） → `reloadData`；`obj.del()` 只擦页面，不再使用。

## 10.14 编辑：layer.open 的 btn / yes + find 改数据

```js
layer.open({
    type:1, title:"编辑学生",
    btn:["保存","取消"],
    content:'<div class="layui-padding-3"><input type="text" id="editName" class="layui-input" value="'+obj.data.studentName+'"></div>',
    yes:function(index){                                   // 点第1个按钮("保存")时执行

        stu.studentName = newName;                         // 先改数据

});
```

```text
btn:[a,b,c]     按钮按顺序对应 yes、btn2、btn3；只看位置，不看文字；没写 btn2 的按钮点了默认关窗
yes(index)      index 是弹窗编号(layer 传入)，用来 layer.close(index)；yes 不会自动关窗
find(函数)       和 filter 类似，但只返回第一个 return true 的那个元素本身(不是数组)
'…'+变量+'…'     拼 HTML 字符串：变量放引号外，用 + 连接；value="…" 给输入框预填内容
先改数据、后 reloadData   顺序反了表格还是旧数据
```

**规则：** 括号里的名字(`obj`、`index`、`s`、`d`、`data`)都是调用者传进来的，名字自己起，值由调用者给；编辑 = 弹窗读新值 → `find` 找到那个学生改属性 → `reloadData`。

yes:function(index){

## 10.16 find 和 filter 的区别

```js
const stu = students.find(function(s){          // find：找到第一个 return true 的，返回这个对象本身
    return s.studentId === "2023002";
});
const girls = students.filter(function(s){      // filter：每个都问一遍，return true 的全留下，返回新数组
    return s.studentGender === "女";
});
```

```text
            find                              filter
找几个      第一个对上就停                    每个都检查
返回        一个对象（数组里那个人本身）      一个新数组（可能 0 个、1 个、多个）
原数组      不变；但改返回的对象 = 改数组里的人  不变
用在哪      编辑：拿到那个人改属性            搜索、筛选、删除：得到一份新名单
```

**规则：** 要改一个人用 `find`（`stu.studentName = …` 改的就是 `students` 里的他，所以 `students` 不用重新赋值）；要一份名单用 `filter`（返回新数组，删除时要 `students = students.filter(…)` 装回去，所以 `students` 用 `let`）。

## 10.17 table 上的 id 和 lay-filter

```html
<table id="studentTable" lay-filter="studentTable"></table>
```

```text
id          给"画表、找表"用：render 的 elem:"#studentTable"、reloadData("studentTable")、checkStatus("studentTable")
lay-filter  给"点击事件"用：table.on("tool(studentTable)")
```

**规则：** 两个名字可以一样，但各管各的：`id` 写错 → 表格不出现 / 重画、查选中无效；`lay-filter` 写错 → 表格正常，点编辑删除没反应。和表单提交按钮上 `id`（给 querySelector）与 `lay-filter`（给 form.on）是同一种分工。

## 11.2 第一个接口

```python
from fastapi import FastAPI     # 导入 FastAPI 类

app = FastAPI()                 # 创建应用：所有接口都登记在 app 上

@app.get("/api/books")          # 登记：GET + /api/books → 交给下面的函数
def get_books():                # 有人访问时，FastAPI 调用它
    return {"name": "三体"}     # 字典 → FastAPI 转成 JSON 发回浏览器
```

```text
main.py
├── from fastapi import FastAPI
├── app = FastAPI()
└── @app.方法("路径")          方法：get 拿 / post 新增 / put 改 / delete 删
    def 函数名():               名字自己起，和网址无关
        return 字典或列表        返回字典用 { }，不是 ( )
```

**规则：** `@app.get` 只登记，不调用；请求来了，FastAPI 按"方法 + 路径"找到函数并调用它（和 `table.on` 一样：先登记，事情来了别人调用你）。一个接口 = 方法 + 路径，缺一样都对不上。

| 看到 | 原因 |
| --- | --- |
| `Could not import module "main"` / `No module named 'main'` | 终端所在目录里没有 `main.py`（放错文件夹、没保存、命令写成 `main.py:app`） |

## 11.4 让服务器提供页面（StaticFiles）

```python
from fastapi.staticfiles import StaticFiles                 # 工具：按文件名找文件、发文件

# ……所有 @app.get 写在上面……

app.mount("/", StaticFiles(directory="."), name="static")   # 上面没登记的地址，一律去当前文件夹找同名文件发回去
```

```text
浏览器要 /api/hello                  → 上面登记过 → 调用 hello()
浏览器要 /13-day6-学生管理页.html    → 没登记 → 交给 mount → 去 D:\Dev\Projects\Layui- 找这个文件 → 发回去
```

| 打开方式 | 地址栏 | 页面里 fetch("/api/...") |
| --- | --- | --- |
| 双击文件 | `file:///D:/...` | 去硬盘问 → 浏览器拦住，失败 |
| 从服务器打开 | `http://127.0.0.1:8000/文件名.html` | 去 8000 问 → 能拿到（同源：页面和数据来自同一个地址） |

**规则：** `mount` 写在文件最后；以后页面一律从 `http://127.0.0.1:8000/文件名.html` 打开，不再双击。

## 11.6 页面用 fetch 向服务器要数据

```js
let books = [];                                       // 先空着
table.render({ elem: "#bookTable", cols: [[…]], data: books });   // 先画空表：画出表头，并把 bookTable 登记成 Layui 表格

fetch("/api/books").then(function (res) {             // fetch：发起请求，第一个参数是地址；then：回信到了才执行，res 是回信（Response）
    return res.json();                                // 拆信：JSON 文字 → JS 数组，交给下一个 then
}).then(function (list) {                             // list：拆出来的数组（= 服务器 return 的列表）
    books = list;                                     // 存进页面变量
    table.reloadData("bookTable", { data: books, page: { curr: 1 } });   // 按新数据重画
});
// 写在这里的代码，比 then 里面的先执行
```

```text
layui.use(..., function(){
├── let 变量 = [];
├── table.render(...)              画空表 + 登记表格（没有它，reloadData 找不到表：warn "table instance ... not found"）
├── fetch(地址)                    发请求，不等
│   .then(res → return res.json())         信到了 → 拆信
│   .then(list → 变量 = list → reloadData)  拆完了 → 存 → 重画
└── table.on / 按钮事件 ……          照常登记，用的还是同一个变量
});
执行顺序：render → fetch 下面的代码 → (服务器回信) → then 里面
```

**规则：** 用到服务器数据的代码写在最后一个 `then` 里面；页面必须从 `http://127.0.0.1:8000/...` 打开（双击打开会报 `URL scheme "file" is not supported`）。页面上删改只动浏览器内存里的变量，刷新就恢复；要真正改，得让服务器改 `main.py` 里的数据（F4 起）。
