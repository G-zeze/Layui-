# Day 5-01：数据表格 table.render（静态数据）

## 0. 开课前回顾：对象 {} 与数组 []

```js
{id:1, name:"张三"}                         // 对象：一个学生，键值对之间用逗号
[ {id:1, name:"张三"}, {id:2, name:"李四"} ]  // 数组：一组学生，元素之间用逗号
```

规则：同一层并列的项用逗号隔开，最后一项后面不加；整条语句结束才用分号。

## 1. table 做什么

你给它两样东西：
1. **数据**：一个数组，每个学生是数组里的一个对象。
2. **列说明**：每一列显示哪个字段、表头叫什么。

它自动画出带表头的表格。你不用手写 `<tr>`、`<td>`。

## 2. 最小示例（课程表，不是你的练习）

```html
<table id="courseTable"></table>
```

```js
layui.use(["table"], function(){
    var table = layui.table;
    table.render({
        elem: "#courseTable",
        cols: [[
            {field:"id", title:"编号", width:80},
            {field:"name", title:"课程名"},
            {field:"teacher", title:"老师"}
        ]],
        data: [
            {id:1, name:"HTML", teacher:"王老师"},
            {id:2, name:"JavaScript", teacher:"李老师"}
        ]
    });
});
```

结构树：

```
table.render(配置对象)
├─ elem  : "#id"            放在哪个 <table> 里（和 laydate 的 elem 一样）
├─ cols  : [[ 列, 列, 列 ]]  列说明（两层方括号，先照写）
│    └─ 每列 {field:"数据里的键", title:"表头文字", width:可选}
└─ data  : [ {对象}, {对象} ] 数据
```

一句话规则：**`field` 必须和数据对象里的键同名**，表格靠它从每个对象里取值。

## 3. 三个关键点

- `elem` 指向的 `<table>` 要有 `id`，`#` 不能漏。
- `use` 数组里要加 `"table"`，`var table = layui.table;` 才有东西。
- 配置对象和 `form`、`laydate` 的套路一致：HTML 标记 → 取模块 → `render(配置)`。

## 4. 你的练习：11-day5-数据表格入门.html

从空文件写，放在根目录。要求：
1. 页面骨架 + 本地 layui.css / layui.js（和 10 号文件同一写法）。
2. 一个 `<table id="studentTable">`。
3. 三个学生，三列：学号、姓名、性别。键名沿用表单：`studentId`、`studentName`、`studentGender`。
4. 不加分页、不接接口。

验收：浏览器里能看到表头和 3 行数据；改一个学生的姓名，刷新后表格跟着变。

## 5. 常见错误（先自查）

- `cols` 少一层方括号：表格不显示。
- `field` 与数据键不一致：该列为空白。
- 对象之间或列之间漏逗号、最后一项多逗号。
- 忘了 `table` 加进 `use` 数组。

## 6. 和第二阶段的衔接

现在 `data` 是写死在页面里的数组。以后接 FastAPI，换成接口返回的数组，`cols` 基本不变。
