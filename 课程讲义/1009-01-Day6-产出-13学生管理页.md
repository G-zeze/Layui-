## 三、JS 框架树

```text
layui.use(["element","table","layer"], function(){
├── ① 取模块 element / table / layer
├── ② let students = [ 8 个学生 ]      键名：studentId / studentName / studentGender / studentClass
├── ③ table.render({ elem, cols, data:students, page:true, limit:5 })
│      cols：checkbox │ 学号 sort │ 姓名 │ 性别 templet(+"生") │ 班级 sort │ 操作 templet(编辑/删除 + lay-event)
├── ④ table.on("tool(studentTable)", function(obj){
│      ├── edit   → layer.open({ type, title, btn, content(预填姓名), yes(index){ 读值→校验→find→改→reloadData→close→msg } })
│      └── delete → layer.confirm(提示, function(index){ filter 去掉→reloadData(page:{curr:1})→close→msg })
│    })
├── ⑤ #searchBtn  click → 读 .value → filter + includes → reloadData(page:{curr:1})
├── ⑥ #addBtn     click → layer.open(4 个输入框, yes(index){ 读 4 个值→校验→push→reloadData(page:{curr:1})→close→msg })
└── ⑦ #showChecked click → checkStatus("studentTable") → msg 条数
})
```

④⑤⑥⑦ 是并列的，都在 `use` 回调里，不要写进彼此的函数里。
