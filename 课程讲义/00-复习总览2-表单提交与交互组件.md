## 1. 页面底部脚本的完整骨架

```html
<script src="./layui-v2.13.9/layui/layui.js"></script>
<script>
    layui.use(["element", "form", "layer", "laydate"], function () {
        const element = layui.element;
        const form = layui.form;
        const layer = layui.layer;
        const laydate = layui.laydate;

        form.render();                       // 1. 渲染下拉框等表单控件
        laydate.render({ elem: "#enrollDate" });   // 2. 日期框绑定日历

        // 3. 登记普通按钮点击
        // 4. 登记表单提交
    });
</script>
```

- 用到哪个模块，`use` 的数组里就要写它的名字，再用 `const x = layui.x` 取出来。
- `element` 负责导航高亮、选项卡切换。即使你不直接用它，也要写在数组里，否则导航和选项卡不会动。
- 所有后面的代码都写在 `use` 的回调函数**里面**。

## 2. 最重要的规则：括号内外的时机不同

```text
交给别人的函数（写在括号里的 function）：先保管，等触发才执行
写在括号外面的语句：读到就马上执行
```

| 写法                                                        | 什么时候执行         |
| ----------------------------------------------------------- | -------------------- |
| `addEventListener("click", function(){ ... })` 里面的内容 | 用户点击时           |
| `form.on("submit(...)", 函数)` 的函数里面                 | 提交且验证通过时     |
| `layer.confirm("...", function(index){ ... })` 的函数里面 | 用户点"确定"时       |
| 写在这些括号外面的语句                                      | 读到那一行就马上执行 |

要等用户点了才做的事，必须写在交给别人的函数**里面**。

## 3. 表单：验证、提交、读取数据

```html
<form class="layui-form">
    <div class="layui-form-item">
        <label class="layui-form-label" for="className">班级名称</label>
        <div class="layui-input-block">
            <input type="text" id="className" name="className"
                   class="layui-input" lay-verify="required"
                   placeholder="请输入班级名称">
        </div>
    </div>

    <div class="layui-form-item">
        <div class="layui-input-block">
            <button type="submit" class="layui-btn" lay-submit lay-filter="saveClass">保存</button>
            <button type="reset" class="layui-btn layui-btn-primary">重置</button>
        </div>
    </div>
</form>
```

```javascript
function saveClass(data) {
    console.log(data.field);     // 例如 { className: "软件2班" }
    layer.msg("已收到表单数据");
    return false;                // 阻止浏览器默认提交（跳转/刷新）
}
form.on("submit(saveClass)", saveClass);
```

对应关系：

```text
button 的 lay-filter="saveClass"
        ↕ 名字一致
form.on("submit(saveClass)", 函数)
```

| 属性/写法                         | 作用                                                                                           |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| `lay-verify="required"`         | 这一项必填，不填会提示，不会调用提交函数                                                       |
| `lay-submit`                    | 告诉 Layui 这个按钮是提交按钮                                                                  |
| `lay-filter="名字"`             | 给提交按钮起名，`form.on` 靠名字找到它                                                       |
| `form.on("submit(名字)", 函数)` | 登记：提交且验证通过时，由 Layui 调用函数                                                      |
| `data.field`                    | 表单数据对象，键来自`name`，值来自输入或 `option` 的 `value`；没有 `name` 的控件不收集 |
| `return false`                  | 让浏览器取消默认提交；写在提交函数的最外层                                                     |

- 重置按钮用 `type="reset"`，不需要 `lay-submit`。
- `layui-btn-primary` 是灰色次要按钮。

## 4. 一个表单项的标准写法（必须记住的层级）

```text
layui-form-item                  ← 每一项单独一个
├── label.layui-form-label       ← 在 input-block 外面，和它平级
└── div.layui-input-block        ← 右侧控件区
    └── input / select
```

文本输入框：

```html
<div class="layui-form-item">
    <label class="layui-form-label" for="phone">联系电话</label>
    <div class="layui-input-block">
        <input type="text" id="phone" name="phone" class="layui-input">
    </div>
</div>
```

下拉框（修改后记得 `form.render()`）：

```html
<div class="layui-form-item">
    <label class="layui-form-label" for="classType">班级类型</label>
    <div class="layui-input-block">
        <select name="classType" id="classType">
            <option value="">请选择</option>
            <option value="day">日间班</option>
            <option value="night">夜间班</option>
        </select>
    </div>
</div>
```

日期输入框和文本框**结构完全一样**，只是多了一个 `id` 用来绑定日历：

```html
<div class="layui-form-item">
    <label class="layui-form-label" for="enrollDate">入学日期</label>
    <div class="layui-input-block">
        <input type="text" id="enrollDate" name="enrollDate"
               class="layui-input" placeholder="请选择日期">
    </div>
</div>
```

- `label` 的 `for` = 控件的 `id`。
- 标签类名是 `layui-form-label`（不是 `layui-label`）。
- 如果 `label` 放进了 `layui-input-block` 里面，会和输入框挤在一起对不齐。

## 5. layer 的四种弹层

| 写法                                          | 效果                             | 点击后           |
| --------------------------------------------- | -------------------------------- | ---------------- |
| `layer.msg("文字")`                         | 通知，几秒后自己消失             | 无               |
| `layer.alert("文字")`                       | 带"确定"按钮的提示框，点确定才关 | 无需写函数       |
| `layer.confirm("文字", 确定函数, 取消函数)` | 带"确定/取消"的询问框            | 取消函数可以不写 |
| `layer.open({...})`                         | 自定义窗口，内容自己决定         | 右上角 × 自带   |

**confirm：**

```javascript
layer.confirm("确定要删除吗?", function (index) {
    layer.msg("已删除");
    layer.close(index);        // 点确定后，要自己关闭确认框
});
```

- 点"确定"：layer 调用你的函数，里面的内容全部执行。
- 点"取消"：函数没有被调用，layer 自己关框。
- `index` 是弹层的编号，由 layer 传给函数；`layer.close(index)` 关闭对应弹层。名字随便取，但括号里和 `close(...)` 里要一致。

**confirm 套在提交函数里（保存前先确认）：**

```javascript
function saveClass(data) {
    layer.confirm("确定要保存吗?", function (index) {
        console.log(data.field);          // 里层函数可以使用外层的 data
        layer.close(index);
        layer.msg("已收到表单数据");
    });
    return false;                         // 在外层，不要放进 confirm 的函数里
}
```

**open（自定义窗口）：**

```javascript
layer.open({
    type: 1,
    title: "窗口标题",
    content: "<div class='layui-padding-3'><p>第一行</p><p>第二行</p></div>",
    area: ["400px", "200px"]
});
```

- `type: 1`：内容是自己写的 HTML；不写默认是文字框。
- `content` 用双引号，里面的 HTML 属性用单引号。
- `layui-padding-3` 是 Layui 自带的内边距类，让内容离窗口边缘 16 像素。

**触发 layer.open 的完整连接：**

```html
<button type="button" id="showInfo" class="layui-btn">查看说明</button>
```

```javascript
const showInfo = document.querySelector("#showInfo");
showInfo.addEventListener("click", function () {
    layer.open({
        type: 1,
        title: "说明",
        content: "<div class='layui-padding-3'>说明内容</div>"
    });
});
```

## 6. laydate：日期选择

三步：

1. 输入框有 `id`（见上面"入学日期"）。
2. `layui.use` 的数组里加 `"laydate"`，再 `const laydate = layui.laydate;`。
3. `laydate.render({ elem: "#enrollDate" });`

- `elem` 写法和 `querySelector` 一样，`id` 前面要有 `#`。
- 选好日期后，输入框里默认是 `2026-10-03` 这种格式；提交时 `data.field` 里的键来自 `name`。
- 日期框加上 `lay-verify="required"` 也可以做必填验证。

## 7. 选项卡 layui-tab

```html
<div class="layui-tab">
    <ul class="layui-tab-title">
        <li class="layui-this">标题一</li>
        <li>标题二</li>
    </ul>
    <div class="layui-tab-content">
        <div class="layui-tab-item layui-show">内容一</div>
        <div class="layui-tab-item">内容二</div>
    </div>
</div>
```

```text
layui-tab
├── ul.layui-tab-title          ← 标题区
│   └── li（默认项加 layui-this）
└── div.layui-tab-content       ← 内容区，和标题区平级
    └── div.layui-tab-item（默认项加 layui-show）
```

- 标题和内容靠**顺序**对应：第 1 个 `li` 对应第 1 个 `layui-tab-item`。
- 默认显示哪一项，标题加 `layui-this`、内容加 `layui-show`，要标在同一项上。
- 切换由 `element` 模块完成，不用写 JS，但 `use` 数组里要有 `"element"`。

## 8. 逗号和分号规则

```text
同一层里，后面还有下一项 → 逗号隔开；没有 → 不加逗号
语句写完 → 分号
```

逗号只出现在三处：

```javascript
// 对象 { } 里，键值对之间
layer.open({
    type: 1,            // 后面还有 → 逗号
    title: "标题",       // 后面还有 → 逗号
    content: "..."      // 最后一项 → 不加
});

// 括号 ( ) 里，参数之间
layui.use(["form", "layer"], function () { ... });

// 数组 [ ] 里，元素之间
["element", "form", "layer"]
```

引号里的逗号只是文字。漏逗号的报错通常是 `Unexpected identifier` 或 `Unexpected token`。

## 9. 常见错误清单（写完先对照一遍）

| 症状                                    | 原因                                                                      |
| --------------------------------------- | ------------------------------------------------------------------------- |
| 样式完全没生效                          | class 拼写错：`calss`、`layui-tab-itme`、`layui-colspace15`         |
| 列之间没有间距                          | 应该是`layui-col-space15`，不是 `layui-colspace15` / `layui-col-15` |
| 标签没对齐、跑到输入框上面              | 标签类名应是`layui-form-label`，不是 `layui-label`                    |
| 标签和输入框挤在一起                    | `label` 被放进了 `layui-input-block`                                  |
| 点链接页面跳转/刷新                     | `href="javascript:;"` 少了 `:;`                                       |
| 下拉框不显示或样子不对                  | 没写`form.render()`，或写在了 `use` 回调外面                          |
| 导航/选项卡不切换                       | `use` 数组里没有 `"element"`，或没引入 `layui.js`                   |
| 确认框一闪就没了                        | `layer.msg` 写在了 `confirm` 括号外面，马上执行并关掉了确认框         |
| 提交后页面刷新、地址栏出现`?name=...` | 没写`return false`，或写进了里层函数                                    |
| `form` 写成 `from`                  | 变量名拼错，控制台报`from is not defined`                               |
| 点了说明按钮之后提交才生效              | 提交的登记写进了点击函数里面，写错层                                      |
| 报错`xxx is not defined`              | 变量没取出来：`use` 数组缺模块，或 `const x = layui.x` 漏写           |

## 10. 出问题怎么查

1. **按 F12 → Console**：看有没有红字，红字会指出文件行号和错误类型。
2. **F12 → 左上角"选择元素"小箭头**，点页面上有问题的地方，右边 Elements 里看这个元素**实际**写了哪些 class 和属性，和本文示例对照。
3. 按层级往外找：`container → row → col → card → form → form-item → label + input-block → 控件`。
4. 脚本问题按顺序查：模块是否写进 `use` 数组 → 是否取出 `const` → 元素 `id` 和 `#id` 是否一致 → 事件是否登记 → 要等点击才做的事是否写在函数里面。
