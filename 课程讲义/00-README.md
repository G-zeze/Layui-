## 讲义写法约定

- 文件名：`月日-序号-标题.md`；第二阶段写成 `月日-序号-FastAPI-F节号-标题.md`。
- 每份讲义固定顺序：这一步解决什么 → 代码 → 是什么 + 对应 → 结构树 → 一句话规则 → 常见错误 → 验收要点。
- 学完一节，速查笔记追加同名小节；讲义可以细，速查要短。
