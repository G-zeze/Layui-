## 1. 还要继续观察的能力缺口

| 缺口 | 现状 | 怎么跟进 |
| --- | --- | --- |
| 函数与回调 | 能用 `then`、`filter`、`confirm` 回调，但写新的嵌套回调要看示例 | 每次新回调先说清"谁调用、什么时候调用、参数谁传" |
| 前后端名字边界 | F3 时把 `main.py` 的函数名用进页面 JS | 新接口都给"示例名 ↔ 页面名 ↔ 服务器名"对照 |
| 说原因 | 验收常能说出现象，原因说不全（如 `file://` 下 fetch 失败） | 验收追问一句"为什么" |
| `form.render()`、`lay-submit` 单属性、`#` 不能漏 | 第一阶段容易忘 | 查速查笔记第三、五章 |

## 2. 反复出现的错误类型

| 类型 | 出现过的例子 | 自查办法 |
| --- | --- | --- |
| 拼写 / 大小写 | `calss`、`from`(form)、`vlaue`、`consoel`、`studnetTable`、`addID`、`layfilter`、`.them` | F12 红字 → 行号 → 逐字母对 |
| 写错层 | 后续步骤写在 `confirm` 括号外、提交登记写进点击函数、`if` 括号里塞函数 | 等触发才做的事写在函数括号里面 |
| 引号 | 拼 HTML 字符串里外引号相同；`title:新增学生` 漏引号 | 外双内单 |
| 脚本 / 文件位置 | `layui.js` 在自己脚本后面；`main.py` 放错文件夹；改了存档 13 号 | 先确认文件和顺序 |
| 照抄示例 | 示例名 `courses` 原样写进自己页面 | 对照表换名 |

## 3. 老师侧教训（接手 agent 必看）

- 讲解过长、提问太浅（2026-10-08）→ 讲解要短，每次最多问 1～2 个关键问题。
- 先讲术语、不说目的（F2"同源"）→ 先说这一步解决什么，名词最后给。
- 讲义太简略、让他猜代码写在哪（F3 fetch）→ 讲义写清位置、分步、名字对照、执行顺序。
- 用过期暂存副本覆盖了新内容；学习者 VS Code 存回旧内容 → 改文档前先核对大小 / 修改时间和上次追加的小节。
- 曾误判代码没对齐 → 下结论前逐行核对。
